## 공통 패턴

1. **무료로 정체성을 준다.** 일간을 "나는 어떤 사람인가"로 보여준다. 서양 점성술의 태양 별자리와 같은 역할이다.
2. **차트 시각화는 무료다.** 4기둥 8글자, 오행 분포.
3. **유료는 주제별 심층 리포트다.** 성격·연애·직업/재물·건강·대운(10년)·올해 운세. PDF 소장이 흔하다.
4. **1회 결제가 주류다.** $8~10 단건이 기준선이고, 궁합·연간 운세 같은 별도 상품과 번들로 객단가를 올린다.
5. **정확도를 강조한다.** 출생 도시 입력, 진태양시 보정, "518,400가지 명식 vs 별자리 12개" 비교.
6. **신뢰 장치를 둔다.** 고전 원문 인용(SajuAstrology), 사람 마스터(Sajumuse), "운명이 아니라 경향" 같은 프레이밍, 7일 환불.
7. **계정 마찰을 줄인다.** 무료 결과는 가입 없이 바로. Cheonmyeongdang은 결제도 계정 없이 받는다.

## 빈틈 (우리가 파고들 곳)

- **공유 장치가 약하다.** 조사한 페이지 어디에도 공유 카드나 친구 초대 흐름이 두드러지지 않는다.
- **"K"가 약하다.** 대부분 고전 한문·신비주의 톤이다. 해외 사용자가 기대하는 한국적 감성(K-컬처)은 거의 쓰지 않는다.
- **무료에 AI 비용을 쓴다.** SajuAstrology처럼 무료 리딩도 AI로 생성하면 무료 사용자가 늘수록 비용이 는다.
- **상품이 너무 많다.** 관상·손금·부적·꿈해몽·Human Design까지 섞여 핵심이 흐려진다.
