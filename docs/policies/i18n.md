# i18n 정책

Status: 논의 중 · 설계는 [../i18n.md](../i18n.md).

### I18N-001 URL은 언어만 나눈다
- 상태: 합의
- 규칙: 기본 언어 한국어는 접두사 없이 `/`, 영어는 `/en/...`. 국가는 URL에 넣지 않는다.

### I18N-002 국가는 값으로 관리한다
- 상태: 합의
- 규칙: 국가는 IP 추정값 + 사용자 설정으로 관리하고 통화·결제·약관 선택에만 쓴다. 국적은 쓰지 않는다.
- 표준 코드: 국가 **ISO 3166-1 alpha-2** (`KR`, `US`, `JP` …), 언어 **BCP 47** (`ko`, `en`), 통화 **ISO 4217** (`USD`), 시간대 **IANA tz** (`Asia/Seoul`).

### I18N-003 번역 책임
- 상태: 합의
- 규칙: 화면에 보이는 문구는 **fe 번역 파일**(`messages/ko.json`, `messages/en.json`, `next-intl`)이 가진다.
  be는 문장이 아니라 코드와 구조화된 값을 돌려준다 (예: 에러 `INSUFFICIENT_CREDITS`, 일간 `gap`).

  | 종류 | 위치 |
  | --- | --- |
  | 버튼·메뉴·안내·에러 메시지·명식 용어 | fe 번역 파일 |
  | 무료 결과 해설 문구 (수백 개) | 콘텐츠 라이브러리 (언어별, 명식 코드로 조회) |
  | 유료 AI 보고서 | AI가 해당 언어로 생성, `locale`과 함께 저장 |

- 근거: Next.js·`next-intl`의 표준 방식. 문구가 한곳에 모이고, 언어 전환이 서버 요청 없이 되며, 문구 수정은 fe 배포만으로 끝난다.

### I18N-004 언어 변경 시 기존 보고서
- 상태: 합의
- 규칙: 언어를 바꿔도 기존 보고서는 원래 언어로 보여주고 "다른 언어로 다시 생성"을 제공한다.
  다시 생성은 새 AI 생성이므로 해당 보고서 가격(상세 리포트 3크레딧)을 정상 차감한다. 기존 응답을 번역·재사용하지 않는다.

### I18N-005 출시 언어
- 상태: 합의
- 규칙: 한국어(`ko`, 기본)와 영어(`en`)로 출시한다. UI 번역 파일과 무료 콘텐츠 라이브러리를 두 언어로 관리한다.
- 파라미터: `i18n.locales` = [ko, en], `i18n.default_locale` = ko

### I18N-006 언어 결정 순서
- 상태: 합의
- 규칙: URL → 사용자가 고른 언어(쿠키) → 브라우저 언어. `/`로 처음 들어온 사용자의 브라우저 언어가 한국어가 아니면 `/en`으로 보낸다.
  지원하지 않는 언어는 영어로 보여준다 (해외 대상 서비스이므로 한국어가 아닌 영어로 대체).
- 파라미터: `i18n.fallback_locale` = en
- SEO: 모든 페이지에 `hreflang`(ko, en, x-default=en)을 둔다.
