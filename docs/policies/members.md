# 회원 정책 (members)

Status: 합의 (plan v0.1.0)

글로벌 서비스에서 일반적인 **최소 식별** 방식을 쓴다. 우리는 사용자가 누구인지 특정할 필요가 없다.

### MEM-001 최소 식별
- 상태: 합의
- 규칙: 실명·전화번호·신분 확인을 하지 않는다. 결제 수단 인증과 부정 결제 방지는 PG가 맡는다.

### MEM-002 계정이 필요한 시점
- 상태: 합의
- 규칙: 입력·무료 결과·공유는 계정 없이 쓴다. 결제와 상세 리포트에는 계정이 필요하다 (구매한 리포트 재열람 보장).

### MEM-003 비회원 명식은 서버에 저장하지 않는다
- 상태: 합의
- 규칙: 비회원의 입력(이름·생년월일·시각·출생 도시·성별)은 서버가 계산에만 쓰고 저장하지 않는다.
  입력값은 사용자 브라우저에만 보관하고, 다시 방문하면 그 값으로 재계산한다.
  가입·결제 시점에 브라우저의 입력값을 서버로 보내 처음 저장한다.
- 근거: 출생 정보와 이름은 개인정보다. 저장하지 않으면 보관 기간·삭제 요청·유출 위험 문제가 생기지 않는다.
  무료 결과는 같은 입력이면 항상 같은 결과이므로 저장할 필요가 없다.
- 관련: 공유 카드는 개인정보 없이 명식 코드만으로 그린다 (사주 정책에서 정의).

### MEM-004 가입·로그인
- 상태: 합의
- 규칙: 비밀번호 없음. 이메일 매직 링크(또는 일회용 코드)와 Google·Apple 로그인만 제공한다.
  이메일 소유 확인은 매직 링크 자체로 끝난다. 같은 이메일의 로그인 수단은 한 계정으로 연결한다.

### MEM-005 수집 항목
- 상태: 합의
- 규칙: 이메일, 로그인 수단 식별자, 선호 언어, 국가(추정값 · 사용자 수정 가능)만 수집한다.
  이름과 출생 정보는 회원 정보가 아니라 명식(사주 도메인) 데이터로 저장한다.

### MEM-006 동의
- 상태: 합의
- 규칙: 이용약관·개인정보처리방침은 필수 동의, 마케팅 수신은 별도 선택 동의(기본 해제).
  EU 등 쿠키 동의가 필요한 지역에서는 필수 쿠키 외 분석·마케팅 쿠키에 동의 배너를 띄운다. 동의 항목·버전·시각을 기록한다.

### MEM-007 연령
- 상태: 합의
- 규칙: 만 16세 미만은 가입할 수 없다. 가입 화면 체크박스로 확인하며 신분 확인은 하지 않는다.
- 파라미터: `member.min_age` = 16

### MEM-008 사용자 권리
- 상태: 합의
- 규칙: 계정 화면에서 내 데이터 내보내기(명식·리포트·결제 내역), 정보 수정(이메일·언어·국가·마케팅 동의), 직접 탈퇴를 제공한다.

### MEM-009 탈퇴 시 데이터 처리
- 상태: 합의

  | 데이터 | 처리 |
  | --- | --- |
  | 계정 정보 | 삭제 |
  | 명식 · 이름 · 출생 정보 · 리포트 | 삭제 |
  | 결제 기록 | MEM-011 보존 기간 동안 사용자와 분리해 보관 후 삭제 |
  | AI 사용 내역 | 사용자 식별자를 제거하고 비용 통계로만 보관 |
  | 남은 크레딧 | 소멸 (탈퇴 확인 화면에서 잔여 수량 안내) |

### MEM-010 세션
- 상태: 합의
- 규칙: 로그인 세션은 HttpOnly 보안 쿠키로 유지한다. 활동이 있으면 연장하고, 기간 동안 활동이 없으면 만료한다. 모든 기기에서 로그아웃할 수 있다.
- 파라미터: `member.session_days` = 30

### MEM-011 결제 기록 보존
- 상태: 합의
- 규칙: 대금 결제·재화 공급 기록 5년, 소비자 불만·분쟁 처리 기록 3년 보존 (법정 기준이라 별도 판단 없이 따른다).
- 근거: 전자상거래법 기록 보존 기준
- 파라미터: `member.retention.payment_years` = 5, `member.retention.dispute_years` = 3

### MEM-012 비활성 계정
- 상태: 합의
- 규칙: 출시 단계에서는 비활성 계정을 자동 정리하지 않는다. 계정 데이터는 탈퇴할 때까지 보관하며, 개인정보처리방침에 "탈퇴 시까지 보관"으로 밝힌다.
- 재검토: 사용자·데이터가 유의미하게 쌓이면 정리 기간을 정한다.

### MEM-014 방문 분석 (GA)
- 상태: 합의
- 규칙: Google Analytics(GA4)로 트래픽·유입 경로·전환(입력 → 무료 결과 → 결제)을 측정한다.
  이름·생년월일·출생 정보·이메일 등 개인정보는 GA로 보내지 않는다. 명식 결과도 보내지 않고 이벤트 이름과 비식별 속성만 보낸다.
  쿠키 동의가 필요한 지역(EU 등)에서는 동의 전에는 분석 쿠키를 쓰지 않는다 (MEM-006).
- 적용 지점: fe
- 미정: 측정할 이벤트 목록 (유저 저니 단계 기준으로 정의)
