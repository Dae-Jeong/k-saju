# AI 사용 내역 정책 (ai_usage)

Status: 합의 · 사주는 "보고서(Report)"로 추상화한 상태에서 정한다.

### AIU-001 기록 항목
- 상태: 합의
- 규칙: LLM 호출마다 보고서 ID, 사용자, 모델, 입력·출력 토큰, 비용, 소요 시간, 성공 여부, **프롬프트 버전**을 기록한다.
  프롬프트 원문은 호출 기록에 저장하지 않는다. 프롬프트는 버전별로 따로 관리하고, 호출 기록은 버전으로 매핑한다.

### AIU-002 비용 계산
- 상태: 합의
- 규칙: 모델별 단가표를 파라미터로 두고, 호출 시점의 단가로 비용을 계산해 함께 저장한다. 단가가 바뀌어도 과거 비용은 변하지 않는다.
- 파라미터: `ai.model_prices`

### AIU-003 동시 생성
- 상태: 합의
- 규칙: 한 사용자가 여러 보고서를 동시에(병렬로) 생성할 수 있다. 각 생성은 시작 시 자기 크레딧을 예약하므로 잔액 이상은 생성되지 않는다.
  단, **같은 명식의 같은 보고서**를 중복 요청하면 새로 생성하지 않고 진행 중이거나 완료된 보고서로 연결한다.

### AIU-004 비용 상한
- 상태: 합의
- 규칙: 앱 안에 일일 비용 상한을 두지 않는다. 생성은 크레딧(유료)으로만 일어나므로 비용은 매출과 함께 움직인다.
  예외 상황(버그로 인한 반복 호출, 보너스·보상 크레딧 사용, 도난 카드 결제 후 차지백)에 대비해 **LLM 공급자 콘솔의 월 사용 한도와 알림**만 설정한다.
- 재검토: 무료 경로에 AI 호출이 생기면 앱 내 상한을 다시 검토한다.

### AIU-005 실패 재시도
- 상태: 합의
- 규칙: LLM 호출 실패 시 자동으로 최대 2회 재시도한다. 그래도 실패하면 보고서를 실패 처리하고 크레딧을 복구한다 (PAY-042).
- 파라미터: `ai.max_retries` = 2

### AIU-006 보관
- 상태: 합의
- 규칙: 기록은 계속 보관한다. 탈퇴하면 사용자 식별자만 지우고 비용 통계로 남긴다 (MEM-009).
