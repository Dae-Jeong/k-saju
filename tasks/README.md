# 작업 기록

작업 하나를 `YYYY-MM-DD-slug.md` 문서 하나로 관리한다. 같은 작업의 수정·검증·배포는 해당 문서의 날짜별 기록에 이어 쓴다.

- 상태: `진행 중` → `검증 완료` → `완료`. `완료`는 요청된 원격 반영·배포까지 확인했을 때 기록한다.
- 문서에는 목표, 예상 결과, 구현 방식과 선택 이유, 검증 근거·한계, 남은 작업을 기록한다.
- 지속되는 제품·설계 기준은 `docs/`가 소유하고, task에서는 해당 문서를 링크한다.
